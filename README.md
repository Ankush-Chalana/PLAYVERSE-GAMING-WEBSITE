# 🎮 PlayVerse

A modern and responsive gaming website built using HTML, CSS, and JavaScript.

PlayVerse showcases featured games, gaming products, community news, and interactive user features within a visually appealing gaming-inspired interface.

---

## 📌 Features

### 🎯 Interactive Gaming Interface
- Modern dark-themed gaming design
- Responsive navigation menu
- Smooth scrolling experience
- Mobile-friendly layout

### 🎮 Featured Games
- Game showcase section
- Real-time search functionality
- Category filtering
- Game detail popups

### ❤️ Favorites System
- Save favorite games
- Dynamic favorites counter
- Interactive notifications

### 🛍️ Gaming Products
- Product showcase cards
- Interactive product details
- Modern card-based layout

### 📰 Latest News
- Featured gaming news section
- Community updates
- Event announcements

### 📧 Community Join Form
- Email validation
- Interactive feedback messages
- JavaScript form handling
